# Code Overview

To construct a polycrystalline diamond model with a relatively high degree of structural order at grain boundaries, this program builds the polycrystalline structure based on truncated octahedral diamond grains.

The entire modeling process consists of three Python scripts that are executed sequentially. First, cubic diamond grains with different crystallographic orientations are cut into regular octahedral grains. The six vertices of each octahedron are then truncated to obtain truncated octahedral grains. Finally, the truncated octahedral grains with different orientations are arranged and assembled according to predefined spatial positions, resulting in an extended Kelvin polycrystalline diamond model containing 16 grains.

## I. octahedron.py

### Function

`octahedron.py` is used to cut the original cubic diamond grains into regular octahedral grains.

The program automatically reads the lattice parameters from the POSCAR files and calculates the geometric center of the model. Based on the user-defined truncation radius `cutoff`, atomic coordinates are filtered, and only atoms satisfying the geometric condition of a regular octahedron are retained.

### Functions Implemented

1. Automatically calculates the geometric center of the model from the lattice vectors.
2. Supports both Cartesian coordinates and Direct fractional coordinates, with automatic coordinate conversion.
3. Batch processes eight diamond grains with different crystallographic orientations: O, A, B, C, D, E, F, and I.
4. Outputs the resulting regular octahedral diamond grain structures.

## II. Truncated1.py

### Function

`Truncated1.py` is used to truncate the regular octahedral grains generated by `octahedron.py` to obtain truncated octahedral diamond grains.

The degree of truncation is controlled by the parameter `truncation_ratio`, with a default value of `0.33`. The program removes the tip regions along the six vertex directions of the regular octahedron, namely ±x, ±y, and ±z, to obtain the truncated octahedral structure.

### Functions Implemented

1. Calculates the geometric center of each octahedral grain and translates the atomic coordinates to a coordinate system centered at the grain center.
2. Performs equal-distance truncation along the +x, -x, +y, -y, +z, and -z directions.
3. Batch processes eight regular octahedral diamond grains with different crystallographic orientations: O, A, B, C, D, E, F, and I.
4. Automatically updates the number of atoms in the POSCAR file according to the actual number of atoms remaining after truncation.

## III. Kelvin1.py

### Function

`Kelvin1.py` is used to arrange and assemble the eight types of truncated octahedral diamond grains with different crystallographic orientations according to predefined spatial positions, ultimately generating an extended Kelvin polycrystalline diamond model containing 16 grains.

The program automatically calculates the geometric dimensions and arrangement parameters of the grains. It also processes atoms near the shared interfaces between adjacent grains, including removing atoms that are too close to each other and adjusting the positions of selected grain-boundary atoms, thereby improving the atomic structure in the grain-boundary regions.

### Functions Implemented

1. Constructs a 16-grain polycrystalline diamond model based on eight types of truncated octahedral grains: O, A, B, C, D, E, F, and I.
2. Automatically calculates the grain dimensions and geometric parameters required for model construction.
3. Detects atoms that are too close to each other between different grains and removes them according to a minimum interatomic distance threshold, with a default value of 1.0 Å.
4. Adjusts the positions of selected atoms near the shared interfaces so that the C–C bond lengths in the interface regions approach the standard diamond bond length of 1.54 Å.
5. Automatically calculates the simulation box dimensions based on the grain arrangement.
6. Performs structural quality checks on the final model, including the minimum interatomic distance and the distribution of C–C bond lengths.

**代码简介**

为了建立晶界处具有较高有序性的多晶金刚石模型，本程序基于截角正八面体晶粒构建多晶结构。

整个建模过程由三个依次执行的 Python 脚本完成。首先，将具有不同晶体取向的立方体金刚石晶粒截取为正八面体；随后对正八面体的六个顶点进行截角处理，获得截角正八面体晶粒；最后将不同取向的截角正八面体晶粒按照预设空间位置进行排列和拼接，构建包含 16 个晶粒的扩展 Kelvin 多晶金刚石模型。

**一、octahedron.py**

**功能介绍**

octahedron.py 用于将原始立方体金刚石晶粒截取为正八面体晶粒。

程序自动读取 POSCAR 文件中的晶格参数并计算模型的几何中心。根据用户指定的截断半径 cutoff，对原子坐标进行筛选，仅保留满足正八面体几何条件的原子。

**程序实现的功能**

1. 根据晶格向量自动计算模型的几何中心。
2. 支持 Cartesian 笛卡尔坐标和 Direct 分数坐标，并可自动进行坐标转换。
3. 批量处理 O、A、B、C、D、E、F、I 共 8 种不同取向的晶粒。
4. 输出截取后的正八面体金刚石晶粒结构。

POSCAR_D1、

0POSCAR_B、
0POSCAR_C、
0POSCAR_D、
0POSCAR_E、
0POSCAR_F、
0POSCAR_I

上述文件为截取后的正八面体晶粒结构。

**二、Truncated1.py**

**功能介绍**

Truncated1.py 用于对 octahedron.py 生成的正八面体晶粒进行截角处理，从而获得截角八面体晶粒。

程序通过截断比例参数 truncation_ratio 控制截角程度，默认值为 0.33。程序沿正八面体的 ±x、±y 和 ±z 六个顶点方向切除尖端区域，从而获得截角八面体结构。

**程序实现的功能**

1. 计算正八面体晶粒的几何中心，并将原子坐标平移至以晶粒中心为原点的坐标系。
2. 沿 +x、-x、+y、-y、+z 和 -z 六个方向进行等距截断。
3. 批量处理 O、A、B、C、D、E、F、I 共 8 种不同取向的正八面体晶粒。
4. 根据截断后的实际原子数量自动更新 POSCAR 文件中的原子数。

**三、Kelvin1.py**

**功能介绍**

Kelvin1.py 用于将 8 种不同取向的截角正八面体晶粒按照指定的空间位置进行排列和拼接，最终生成包含 16 个晶粒的扩展 Kelvin 多晶金刚石模型。

程序能够自动计算晶粒的几何尺寸和排列参数，并对相邻晶粒共享界面附近的原子进行处理，包括删除距离过近的原子以及调整部分晶界原子位置，从而改善晶粒连接区域的原子结构。

**程序实现的功能**

1. 基于 O、A、B、C、D、E、F、I 共 8 种不同取向的截角正八面体晶粒构建 16 晶粒多晶模型。
2. 自动计算晶粒尺寸以及模型构建所需的几何参数。
3. 检测不同晶粒之间距离过近的原子，并根据最小原子间距阈值进行删除，默认阈值为 1.0 Å。
4. 调整共享界面附近部分原子的位置，使界面区域的 C-C 键长接近金刚石标准键长 1.54 Å。
5. 根据晶粒排列自动计算模拟盒子的尺寸。
6. 对最终模型进行结构质量检查，包括最小原子间距以及 C-C 键长分布等信息。
